# Job Matcher

Личный сервис для поиска работы. Он собирает вакансии из открытых источников, сравнивает их
с профилем кандидата (навыки, опыт, зарплата, формат работы) и показывает, какие подходят
и **почему**.

[![CI](https://github.com/helena2000cher-hub/job/actions/workflows/ci.yml/badge.svg)](https://github.com/helena2000cher-hub/job/actions/workflows/ci.yml)

План и исследование — в [PLAN.md](PLAN.md), деплой — в [docs/DEPLOY.md](docs/DEPLOY.md).

## Возможности

- [x] Сбор вакансий из «Работы России» (открытый API trudvsem.ru)
- [x] Exa: hh.ru, Хабр Карьера и карьерные страницы компаний по запросам из профиля
  (структурированные поля извлекает сам Exa, архивные и «ложно удалённые» отсеиваются по тексту страницы)
- [x] SuperJob через официальный API (бесплатный ключ: https://api.superjob.ru/register/ → «Secret key»
  на https://api.superjob.ru/info/ → строка `SUPERJOB_API_KEY=...` в `.env`)
- [x] Определение удалённых вакансий
- [x] Профиль от навыков: «Кем я могу работать» — профессии, подобранные по навыкам (основные,
  смежные, другие сферы) с процентом совпадения, «пригодится» и «подтянуть»; выбор профессии
  добавляет её запросы в поиск; искать можно по профессиям, по навыкам или по тому и другому
- [x] Профиль из резюме (LLM через polza.ai), контакты вычищаются перед отправкой в модель.
  Резюме — тремя способами: файл (PDF, DOCX, ODT, RTF, TXT), ссылка (hh.ru, Хабр Карьера,
  Google Документ, любая открытая страница) или анкета по разделам, как на hh.ru. Навыки из нового
  резюме добавляются к уже имеющимся, выбранные профессии и ручные правки сохраняются
- [x] Подбор: жёсткие фильтры → смысловая близость (эмбеддинги) → оценка LLM 0–100 с объяснением
- [x] Кэш эмбеддингов и оценок: повторный запуск не тратит деньги, пока не изменились профиль или вакансия
- [x] Веб-интерфейс: лента с фильтрами, карточка вакансии с разбором, редактор профиля,
  «Обновить» с выбором источников и прогрессом, скрыть ненужное, тёмная тема, мобильная вёрстка
- [x] Трекер откликов: канбан «Интересно → Отклик отправлен → Собеседование → Оффер / Отказ»,
  перетаскивание, заметки, контакт, дата отклика
- [x] Вопрос «Отправили отклик?» после перехода на сайт работодателя — отклик сам встаёт в трекер;
  через 10 дней без ответа карточка переходит в «Без ответа»; отдельные этапы «Анкета» и «Тестовое задание»
- [x] Ручное добавление отклика (например, отправленного прямо на hh.ru): по ссылке данные
  подтягиваются через Exa, без ссылки — по названию и компании
- [x] Аналитика откликов: список «Мои отклики» со сменой этапа, доля приглашений по тону письма, баллу совпадения и сайту, частые
  пробелы в навыках и советы нейросети по резюме и письмам
- [x] Сопроводительное письмо под вакансию: факты только из резюме, честно о пробелах,
  деловой или дружелюбный тон, правка и копирование
- [x] Публичный сайт: гостям — демо на вымышленных данных (песочница со сбросом),
  владельцу — вход по паролю (подписанная HttpOnly-cookie, защита от перебора)
- [x] Docker + Caddy (автоматический HTTPS), CI на GitHub Actions с автодеплоем на VPS
- [ ] Больше источников: Telegram-каналы, SuperJob

## Стек

**Backend:** Python 3.12 · FastAPI · SQLModel/SQLite · httpx · OpenAI SDK (polza.ai: DeepSeek, Claude Haiku, bge-m3) · Exa · pypdf · pytest · ruff
**Frontend:** React 19 · TypeScript · Vite · Tailwind CSS 4 · lucide-react

## Быстрый старт

**Windows, когда всё уже установлено:** двойной клик по `start.bat` — откроется http://localhost:8000
(сервер работает в свёрнутом окне). Остановить — `stop.bat`.

```bash
# backend
cd backend
py -m venv .venv
.venv\Scripts\activate          # Windows; на Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
copy ..\.env.example ..\.env     # и заполнить ключи POLZA_API_KEY, EXA_API_KEY

# профиль из резюме: data/resume.pdf → data/profile.json
python -m app.profile

# веб-интерфейс: API на :8000
uvicorn app.api.main:app --reload

# во втором терминале — фронтенд на :5173 (запросы /api проксируются на :8000)
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173, затем «Обновить» → выбрать источники → «Начать».

Для продакшена `npm run build` собирает фронтенд в `frontend/dist`, и FastAPI отдаёт его сам:
весь сервис работает как один процесс на :8000. На сервере: `docker compose up -d --build`
(подробно — [docs/DEPLOY.md](docs/DEPLOY.md)).

### Командная строка

```bash
python -m app.collect --query "аналитик"                              # Работа России, Пермский край
python -m app.collect --query "аналитик" --all-regions --remote-only  # удалёнка по всей России
python -m app.collect --source exa --from-profile --limit 30          # hh.ru, Хабр, сайты компаний (~$0.5)
python -m app.match --min-score 60                                    # подбор с объяснениями
pytest
```

## Как устроен подбор

1. **Фильтры:** формат работы, потолок зарплаты ниже минимума, стоп-слова («склад», «курьер»…).
2. **Дубли:** одна вакансия в разных регионах оценивается один раз.
3. **Смысловая близость:** эмбеддинги профиля и вакансий (`baai/bge-m3`), в LLM уходит только топ.
4. **Оценка LLM:** балл 0–100, совпавшие и недостающие навыки, «красные флаги», вердикт.

## Структура

```
backend/app/
  api/          # FastAPI: лента, трекер, письма, «Обновить», вход и демо-режим
  demo.py       # демо-песочница из backend/demo/seed.json (всё вымышлено)
  collectors/   # источники вакансий: trudvsem, exa (hh.ru, Хабр, сайты компаний)
  matching/     # фильтры, эмбеддинги, LLM-оценка, конвейер
  collecting.py # сбор по списку запросов (общий для CLI и API)
  cover_letter.py # сопроводительное письмо (LLM, факты из резюме)
  llm.py        # клиент polza.ai (чат + эмбеддинги)
  profile.py    # профиль кандидата из резюме
  models.py     # Vacancy, VacancyEmbedding, Match, VacancyMark, Application
frontend/src/
  components/   # лента, карточка, трекер, профиль, кнопка «Обновить»
  api.ts        # типизированный клиент API
data/           # локальная БД, резюме и профиль — не попадают в git
```

## Коммерческий режим

`PUBLIC_MODE=true` в `.env` скрывает от пользователей внутреннюю кухню: стоимость поиска и
нейросетей, названия внутренних сервисов (Exa, polza.ai) и неподключённые источники. Журнал
поиска в обоих режимах показывает понятный прогресс («Ищу на hh.ru и Хабр Карьера…»).

## Приватность и безопасность

Резюме, профиль, база вакансий и ключи API хранятся только локально (`data/`, `.env`)
и в репозиторий не попадают. Перед отправкой резюме в LLM из него удаляются телефон, email и дата рождения.
Гости сайта работают только с отдельной демо-базой, платные функции (сбор, письма) им недоступны.
